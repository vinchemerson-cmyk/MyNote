# 公式速查与字幕修订记录

## 公式速查

本表默认连续时间、负反馈；$S,T$ 采用单位反馈。每条公式仍需满足对应专题的稳定性与模型假设。

| 内容 | 公式 |
|---|---|
| 一般反馈参考通道 | $Y/R=CG/(1+CGH)$ |
| 单位反馈环路 | $L=CG$ |
| 灵敏度 | $S=1/(1+L)$ |
| 互补灵敏度 | $T=L/(1+L)$ |
| 互补恒等式 | $S+T=1$ |
| 输出扰动与测量噪声 | $Y=TR+SD-TN$ |
| 终值定理 | $f(\infty)=\lim_{s\to0}sF(s)$，先检查 $sF$ 极点 |
| PI | $C=K_p+K_i/s$ |
| 标准 PID | $C=K_p(1+1/(T_is)+T_ds)$ |
| 参数换算 | $K_i=K_p/T_i,\ K_d=K_pT_d$ |
| 根轨迹特征式 | $1+KL_0=0,\ K\ge0$ |
| 根轨迹幅值 | $K=1/\lvert L_0(s_d)\rvert$ |
| 根轨迹相角 | $\angle L_0(s_d)=(2q+1)\pi$ |
| 超前 | $K(s+z)/(s+p),\ 0<z<p$ |
| 滞后 | $K(s+z)/(s+p),\ 0<p<z$ |
| Nyquist | $N_{\rm ccw}=P-Z$，逆时针为正 |

## 修订记录

原字幕没有逐句时间戳。下面以课程编号和可搜索的关键词追溯；无法仅凭文字断定是讲者口误还是自动识别错误的地方，统一称“字幕表述”。

| 来源 | 字幕中的问题或歧义 | 整理后的处理 |
|---|---|---|
| 1 | “E 等于二……过热” | $e=r-y<0$ 才表示实际温度过高 |
| 1 | “输出是输出的函数” | 输入受反馈输出影响 |
| 2 | “B 和 C 都是 BIBO 稳定” | 区分无输入稳定与 BIBO；补无阻尼共振反例 |
| 2 | 分子分母符号混乱、共轭根示例多项式含混 | 统一 $N/D$；按 $-1\pm j$ 恢复 $s^2+2s+2$ |
| 2.5 | “新的传递函数” $X/(U+x_0)$ | 保留零状态传递函数定义，分离初始状态响应 |
| 3 | “七1”“game”“Max”等 | 恢复 $1/7000$、Gain、Mux；明确时间单位 |
| 3 | 仿真器进行拉普拉斯正逆变换 | 改为通过状态方程数值求解 |
| 4 | 把输出变换中的原点根与系统根混说 | 分开输入极点与闭环极点 |
| 5 | 稳定条件 $K_p>1$ | 对 $\tau s+1$ 对象应为 $K_p>-1$ |
| 5 | 终值定理只看“所有极点在左边” | 明确检查的是 $sF(s)$，不是含输入项的 $F$ 全部极点 |
| 5、6 | “比例控制无法消除任何稳态误差” | 限定本例及输入；补型别、前馈等边界 |
| 6 | $K_i$ 项漏乘输出 | 恢复 $\tau\ddot y+\dot y+K_i y=K_i r$ |
| 8 | $s+1$ 的零点写成 $+1$ | 恢复为 $-1$ |
| 9 | 分离点与汇合点交替称呼 | 按增益增大时进入或离开实轴区分 |
| 9 | $KL_0=1$、几何例子负号丢失 | 恢复 $KL_0=-1$ 与 $s_d=-1+j\sqrt3$ |
| 10 | 超前“提高稳定性”被泛化 | 补充全部闭环根、裕度和噪声的检查 |
| 11 | 滞后不影响瞬态的绝对说法 | 说明相对较小的扰动与可能的慢尾巴 |
| 12 | 微分后约 3000 的输入峰值 | 区分理想冲激与具体仿真实现 |
| 12.5 | 标准 PID 括号与滤波分母不清 | 恢复 $K_p(1+1/(T_is)+T_ds/(1+T_ds/N))$ |
| 13 | 绕行正负、传感器符号混乱 | 统一逆时针为正；传感器模型标为待原图确认 |
| 15 | “补偿灵敏度” | 修订为“互补灵敏度” |
| 15 | $\lvert S\rvert,\lvert T\rvert\le1$、幅值平方互补 | 改为复数恒等式 $S+T=1$，补反例 |
| 15 | 高频/低频、高通/低通叙述前后颠倒 | 统一低频大环路增益、高频小环路增益 |
| 16 | 有持续正弦扰动时称输出精确稳定为常数 | 分开直流分量与剩余正弦纹波 |

2. 阶跃响应的 $Y(s)$ 含 $1/s$，为什么不能据此说闭环不稳定？
3. 增加积分为何能保留一个非零平衡输入？
4. 根轨迹为什么由开环模型计算，却描述闭环极点？
5. 相角条件满足后，还缺什么才能确定控制增益？
