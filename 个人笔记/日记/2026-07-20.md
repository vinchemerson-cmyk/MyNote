今天我对比了2006和6020的通信协议,以下是具体的对比统计：

### 一、 控制指令（接收报文）区别

这两款设备在接收控制指令时，支持的控制模式、标识符（ID）分配以及给定的数据范围均不相同。

| **特性**       | **GM6020 电机**                 | **M2006 电机 (配合 C610 电调)**     |
| ------------ | ----------------------------- | ----------------------------- |
| **支持的控制模式**  | 支持电压控制和电流（转矩）控制               | 仅支持电流（转矩）控制                   |
| **支持的最大设备数** | 最多支持 7 个电机（ID 范围：1-7）         | 最多支持 8 个电调（ID 范围：1-8）         |
| **电压控制标识符**  | ID 1-4：`0x1FF`，ID 5-7：`0x2FF` | 不支持该模式                        |
| **电压给定值范围**  | -25000 ~ 25000                | 不适用                           |
| **电流控制标识符**  | ID 1-4：`0x1FE`，ID 5-7：`0x2FE` | ID 1-4：`0x200`，ID 5-8：`0x1FF` |
| **电流给定值范围**  | -16384 ~ 16384                | -10000 ~ 10000                |
| **对应最大实际电流** | -3A ~ 3A                      | -10A ~ 10A                    |

### 二、 状态数据（反馈报文）区别

两者在向总线发送反馈数据时，标识符的计算方式、默认频率以及数据帧的具体字节定义存在差异。

| **特性**     | **GM6020 电机**           | **M2006 电机 (配合 C610 电调)** |
| ---------- | ----------------------- | ------------------------- |
| **反馈标识符**  | `0x204` + 驱动器 ID        | `0x200` + 电调 ID           |
| **发送频率**   | 1KHz，固定频率               | 1KHz，(可通过调参软件修改)          |
| **字节 0-1** | 机械角度高、低 8 位 (数值 0~8191) | 机械角度高、低 8 位 (数值 0~8191)   |
| **字节 2-3** | 转速高、低 8 位 (单位：rpm)      | 转速高、低 8 位 (单位：rpm)        |
| **字节 4-5** | 实际转矩电流高、低 8 位           | 实际转矩电流高、低 8 位             |
| **字节 6**   | 包含电机温度信息                | 数据为空 (保留位)                |
| **字节 7**   | 数据为空 (Null)             | 包含电机错误码                   |

### 三、 异常与错误处理反馈区别

在总线的数据反馈层面上，M2006 配合 C610 电调的设计提供了更详细的错误状态码。

- **GM6020**：反馈报文中不包含独立的错误代码位（字节 7 为空）。其异常情况主要通过机身上的指示灯进行提示，并在异常时直接关闭输出。
    
- **M2006 (C610)**：将反馈报文的第 7 个字节专门分配为电机错误码，可以直接通过 CAN 总线读取具体异常（如电压过高、三相线未接入、数据线丢失、电机堵转或校准失败等），并且在存在多个错误时优先反馈级别更高的错误码。
