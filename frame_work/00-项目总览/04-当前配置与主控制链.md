# 当前配置与主控制链

## 编译配置

`application/robot_def.h` 当前选择：

- `ONE_BOARD`：一块开发板控制整车；
- `VISION_USE_VCP`：视觉通信发送侧使用 USB 虚拟串口；
- 麦克纳姆轮参数：轴距 350 mm、轮距 300 mm、轮半径 60 mm；
- 当前只启用 CMD 和 Chassis 应用。

## 硬件分配

| 功能 | 外设 |
|---|---|
| 遥控器 DBUS | UART3 |
| 视觉通信配置 | UART1 / USB VCP 条件编译 |
| 裁判系统 | UART6 |
| 四个 M3508 底盘电机 | CAN1，ID 1、2、4、3 |
| 超级电容 | CAN2，接收/发送 ID 0x301/0x302 |
| 板载 BMI088 | SPI1 等 CubeMX 配置外设 |

## 主控制链

```text
UART3 DMA 收到 DBUS
→ HAL_UARTEx_RxEventCallback
→ RemoteControlRxCallback
→ sbus_to_rc 更新 rc_data
→ RobotCMDTask 读取 rc_data
→ 生成 Chassis_Ctrl_Cmd_s
→ PubPushMessage("chassis_cmd")
→ ChassisTask 获取消息
→ 坐标旋转 + 麦克纳姆轮解算
→ DJIMotorSetRef
→ 1 kHz MotorControlTask
→ PID/功率控制
→ CAN1 电流指令
```

## 电机反馈链

```text
电调 CAN 反馈
→ HAL_CAN_RxFifoXMsgPendingCallback
→ BSP CAN 按总线和 ID 查找实例
→ DecodeDJIMotor
→ 更新编码器、速度、电流、温度和多圈角度
→ DaemonReload
→ 下一次电机控制使用最新反馈
```
