# INS 与旧版 BMI088

这是当前项目实际使用的姿态解算链路，位于 `modules/imu`。

## 文件分工

- `BMI088Middleware`：SPI1 字节收发和 Acc/Gyro 片选控制；
- `BMI088driver`：寄存器初始化、读取、标定和温度；
- `ins_task`：温控、坐标修正、四元数 EKF、姿态输出。

## 初始化

`INS_Init()`：

1. 保证只初始化一次；
2. 启动 TIM10 PWM 加热；
3. 初始化并标定 BMI088；
4. 平均读取 100 次加速度确定初始 Roll/Pitch，Yaw 设为 0；
5. 初始化四元数 EKF；
6. 初始化温度 PID；
7. 返回姿态数据指针。

代码通过强制转换返回 `&INS.Gyro` 作为 `attitude_t *`，依赖 `INS_t` 的字段布局，源码自己也标注这是待修写法。修改结构体顺序时风险很高。

## 1 kHz 更新

`INS_Task()` 每次：

- 通过 DWT 获取真实 `dt`；
- 读取加速度和陀螺仪；
- 修正安装误差；
- 调用四元数 EKF；
- 计算机体系/导航系向量；
- 去除重力并低通运动加速度；
- 更新 Yaw、Pitch、Roll 和累计 Yaw；
- 把姿态交给视觉发送数据。

温度 PID 每两次运行一次，即约 500 Hz，目标温度当前为 40°C。

## 输出

`attitude_t` 提供三轴陀螺仪、欧拉角和 `YawTotalAngle`，云台可把这些字段作为外部角度/速度反馈。

## 注意

- 坐标系和正方向必须结合 C 板安装方向确认；
- 上电标定期间机器人应保持静止；
- 初始化失败采用死循环重试，传感器断开会卡在启动阶段；
- 当前 Gimbal 被关闭，但 INS 任务仍持续运行并发送视觉数据。
