# IST8310 磁力计

IST8310 通过 I²C 读取三轴磁场，DRDY 引脚产生外部中断，另有一个 GPIO 控制复位。

## 初始化配置

`IST8310_Init_Config_s` 包含：

- IIC 配置；
- Reset GPIO 配置；
- Data Ready EXTI GPIO 配置。

`IST8310Init()` 注册三个 BSP 实例，复位芯片，检查 WHO_AM_I = `0x10`，再写入平均次数、输出频率等寄存器并读回校验。

## 数据链

```text
DRDY EXTI
→ IST8310StartTransfer
→ IICAccessMem 读取 6 字节
→ IST8310Decode
→ int16 三轴原始值 × 0.3
→ mag[3]，单位 µT
```

当前传输实际是阻塞的，虽然 IIC BSP 支持异步模式。

## 注意

- I²C 地址固定为 `0x0E`，同一总线不能挂两个相同地址器件；
- 初始化使用 `HAL_Delay(50)`。如果在 `RobotInit()` 关闭中断期间调用，HAL tick 可能不更新而卡死；应改用 DWT 延时或调整初始化时机；
- 磁力计需要软硬铁标定，并远离电机、电源线和铁磁结构；
- 当前 INS 没有融合磁力计，Yaw 主要由陀螺积分，长期会漂移。
