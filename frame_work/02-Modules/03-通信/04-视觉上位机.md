# 视觉上位机通信

## 模块组成

- `master_process.c/h`：视觉收发数据、接口和 UART/USB 条件编译；
- `seasky_protocol.c/h`：帧头、数据长度和 CRC 解析/封包；
- `湖南大学RoboMaster电控组通信协议.md`：协议说明。

## 数据

`Vision_Recv_s` 主要保存目标状态和视觉给出的 Pitch/Yaw 信息；`Vision_Send_s` 保存机器人姿态、敌方颜色、工作模式和弹速等。

## 接口

```c
Vision_Recv_s *VisionInit(UART_HandleTypeDef *handle);
void VisionSetFlag(...);
void VisionSetAltitude(float yaw, float pitch, float roll);
void VisionSend(void);
```

## 两种传输方式

- `VISION_USE_UART`：通过 USART BSP 收发；
- `VISION_USE_VCP`：通过 USB CDC/VCP 收发。

当前配置是 VCP。`VisionSend()` 在 INS 解算之后约 1 kHz 被调用，但实际视觉链路通常不需要如此高频，应该结合 USB 状态和上位机需求控制频率。
