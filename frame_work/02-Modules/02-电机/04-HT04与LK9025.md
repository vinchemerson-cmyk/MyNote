# HT04 与 LK9025

## HT04

HT04 使用类似 MIT 的紧凑 CAN 控制帧，包含位置、速度、KP、KD 和力矩等字段，并提供特殊模式命令。

主要接口：

```c
HTMotorInit(...);
HTMotorSetRef(...);
HTMotorOuterLoop(...);
HTMotorEnable(...);
HTMotorStop(...);
HTMotorCalibEncoder(...);
HTMotorControlInit();
```

代码可以为电机建立独立 FreeRTOS 控制任务。原因是 HT04 收到一帧后会立即反馈，如果把多个设备简单集中高频发送，容易形成总线拥塞。`OSTaskInit()` 总会调用 `HTMotorControlInit()`，未注册 HT 电机时不会创建有效控制工作。

## LK9025

LK9025 是瓴控电机 CAN 封装，模块解析温度、电流、速度和编码器信息，并支持内部 PID 后发送协议命令。

主要接口：

```c
LKMotorInit(...);
LKMotorSetRef(...);
LKMotorControl();
LKMotorEnable(...);
LKMotorStop(...);
LKMotorIsOnline(...);
```

当前统一 `MotorControlTask()` 中 `LKMotorControl()` 被注释，需要使用时手动启用或改为根据注册数量条件执行。

## 共同注意点

- 两种电机协议与 DJI 分组协议不同；
- 确认发送 ID、反馈 ID、工作模式和电机固件；
- 在线判断依赖 Daemon 反馈喂狗；
- 不同协议共用 CAN 时要计算总线负载和反馈频率。
