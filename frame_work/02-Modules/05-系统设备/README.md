# 系统设备模块总览

| 模块 | 作用 | 当前使用情况 |
|---|---|---|
| Daemon | 通信/设备离线检测与恢复回调 | 广泛使用 |
| Buzzer | PWM 声音和分级报警 | Daemon Task 中运行 |
| Referee/UI | 裁判系统接收、交互数据与客户端 UI | Chassis/UI Task 使用 |
| Super Cap | CAN 超级电容数据与控制 | Chassis 已初始化 |
| OLED | I²C 128×64 显示 | 可选，当前未进入整车任务 |

这些模块关系到安全状态和比赛规则数据，调试时要特别区分“收到数据”和“数据可信/及时”。
