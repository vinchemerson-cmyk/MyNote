# 蜂鸣器与报警

蜂鸣器使用 TIM4 Channel 3 的 PWM，通过周期控制音高、占空比控制响度。

## 接口

```c
void BuzzerInit(void);
BuzzzerInstance *BuzzerRegister(Buzzer_config_s *config);
void AlarmSetStatus(BuzzzerInstance *instance, AlarmState_e state);
void BuzzerTask(void);
```

报警实例以 `AlarmLevel_e` 作为数组位置；任务按优先级从高到低查找第一个开启的报警并输出相应音符。

## 音高

代码预定义 Do/Re/Mi/Fa/So/La/Si 频率，`octave_e` 实际被用作选择这些音符，而不是传统意义上的八度倍频，命名略有误导。

## 当前问题

`buzzer_list` 初始元素为 NULL，但 `BuzzerTask()` 直接访问 `buzz->alarm_level`。如果没有为每个槽位注册实例，存在空指针 HardFault 风险。正常逻辑应先判断 `buzz == NULL`。

此外，Daemon 中的“自动触发蜂鸣器/LED 报警”仍是 TODO，需要业务模块主动注册报警并设置状态。
