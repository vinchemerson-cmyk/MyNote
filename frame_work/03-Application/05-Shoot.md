# Shoot

Shoot 示例包含两个 M3508 摩擦轮、一个 M2006 拨盘和计划中的弹舱盖舵机。

## 电机

- 左摩擦轮：CAN2 ID1；
- 右摩擦轮：CAN2 ID2，方向反转；
- 拨盘：CAN2 ID3。

## 控制命令

`Shoot_Ctrl_Cmd_s` 包含：

- 总开关；
- 拨盘停止、反转、单发、三发、连发；
- 舱盖开关；
- 摩擦轮开关；
- 弹速、剩余热量和射频。

## 周期流程

1. 获取 `shoot_cmd`；
2. 根据总模式启停三个电机；
3. 根据拨盘模式切换角度环/速度环；
4. 根据弹速设置摩擦轮目标；
5. 控制舱盖；
6. 发布 `shoot_feed`。

单发/三发设计通过当前多圈角度增加固定角度。连发把“发/秒”换算为拨盘速度。

## 当前不可直接使用的原因

- 整个应用入口被注释；
- 所有电机 PID 参数基本为 0；
- 15/18/30 m/s 对应的摩擦轮目标全部是 0，默认分支却是 30000；
- 舱盖控制为空；
- 拨盘反转为空；
- 单发/三发防重复触发的休眠判断被注释，持续收到命令会不断增加角度目标；
- 卡弹检测、热量限制和有效反馈未实现；
- 连发公式中使用常数 8，与 `NUM_PER_CIRCLE` 的配置没有统一。

启用前需要完成标定、安全联锁和机构测试，不能只取消两处注释。
