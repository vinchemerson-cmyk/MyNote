# RobotCMD

RobotCMD 是整车命令中枢：读取遥控器/键鼠/视觉和应用反馈，生成定量控制命令，进行安全处理，然后发布。

## 初始化

当前初始化：

- UART3 遥控器；
- UART1 参数传给视觉初始化，当前 VCP 模式下该参数被忽略；
- 注册 Gimbal/Shoot 命令发布者和反馈订阅者；
- 单板模式注册 Chassis 命令发布者和反馈订阅者；
- 双板模式改为 CANComm；
- 初始状态设为 `ROBOT_READY`。

## 周期流程

```text
读取 chassis/gimbal/shoot 反馈
→ CalcOffsetAngle
→ 根据左开关选择 RemoteControlSet 或 MouseKeySet
→ EmergencyHandler
→ 发布三个应用命令
```

## 遥控器模式

- 左开关下：摇杆控制；
- 左开关中：计划中的视觉模式；
- 左开关上：键鼠模式；
- 右开关下：底盘小陀螺；
- 右开关中：底盘不跟随；
- 右开关上：恢复工作状态/舱盖相关设计。

拨轮控制摩擦轮、连发和急停。具体阈值目前是经验值。

## 急停

拨轮向下超过阈值或整车状态为 STOP 时：

- 云台零力；
- 底盘零力；
- 发射关闭；
- 摩擦轮关闭；
- 拨盘停止。

## 当前问题

- Gimbal 被关闭，`gimbal_feed` 没有真实数据，底盘与云台偏角通常为零；
- 视觉模式只有占位逻辑；
- 键鼠横移表达式使用了 `S - D`，按常规 WASD 语义很可能应检查为 `A - D`；
- 键鼠小陀螺、鼠标发射等说明文档与实际代码并未完全对应；
- 输入增益、角度限位和模式切换平滑都需要实车调试。
