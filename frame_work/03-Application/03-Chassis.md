# Chassis

当前是四轮麦克纳姆底盘示例。

## 拥有的模块

- 四个通过 `PowerControlInit()` 注册的 M3508；
- 裁判系统和 UI 数据；
- 底盘缓冲能量 PID；
- CAN2 超级电容；
- 单板 Message Center 或双板 CANComm；
- 双板底盘模式可额外初始化 INS。

## 电机配置

四个电机位于 CAN1，ID 顺序：

```text
LF=1, RF=2, LB=4, RB=3
```

速度 PID 当前约为 `Kp=4.5`，其余参数和方向需要按实车验证。

## 周期流程

1. 获取 `Chassis_Ctrl_Cmd_s`；
2. 用裁判系统数据更新最大功率；
3. 根据模式启停四电机；
4. 计算旋转速度；
5. 按云台偏角把速度从云台系旋转到底盘系；
6. 麦克纳姆轮运动学解算；
7. 设置四电机参考值；
8. 估计真实速度；
9. 发布反馈。

## 模式

- `ZERO_FORCE`：停止四电机；
- `NO_FOLLOW`：`wz = 0`，允许平移；
- `FOLLOW_GIMBAL_YAW`：按偏角生成跟随角速度；
- `ROTATE`：当前直接令 `wz = 4000`。

## 当前问题

- `EstimateSpeed()` 为空；
- 反馈中的敌方颜色、弹速和热量代码被注释；
- 缓冲能量 PID 与超级电容尚未接入最终控制；
- 跟随模式对 float 使用普通 `abs()`，应检查是否应该使用 `fabsf()`；
- 裁判系统尚未收到数据时功率限制可能为零；
- 只实现麦轮，舵轮、全向轮和平衡底盘头文件是规划/占位。
