# 阅读和调试方法

## 每个模块记录五项

1. 谁初始化它；
2. 它拥有哪些实例；
3. 输入从哪里来；
4. 输出到哪里去；
5. 周期任务还是中断回调。

## 函数命名速查

- `Init/Register`：初始化、申请实例、注册 BSP；
- `Task/Control`：周期执行；
- `Callback/Decode`：中断/接收后调用；
- `SetRef/Set/Get/Send`：上层接口；
- `Enable/Stop`：设备状态；
- `static`：仅当前 `.c` 使用的私有实现。

## 推荐断点

底盘链可以依次设置：

```text
RemoteControlRxCallback
RobotCMDTask
ChassisTask
DJIMotorSetRef / PowerControl
DecodeDJIMotor
HAL_CAN_RxFifo0MsgPendingCallback
```

中断断点会明显改变系统时序，确认调用关系后应改用 RTT 日志、Live Watch 或 Ozone 观察变量。

## 推荐观察变量

- 遥控器：原始缓冲区、`rc_data[TEMP]`；
- CMD：三个 `*_cmd_send`；
- Chassis：`chassis_vx/vy`、四个 `vt_*`；
- 电机：`pid_ref`、`measure.speed_aps`、PID 输出、最终 CAN 字段；
- Daemon：`temp_count`；
- INS：`dt`、Gyro/Accel、四元数和 Yaw/Pitch/Roll。

## 二分定位

电机不转时不要直接调 PID，按顺序确认：

```text
是否发布命令
→ Chassis 是否收到
→ SetRef 是否变化
→ Motor Task 是否运行
→ CAN 发送值是否非零
→ 电调是否反馈
→ 方向和闭环是否正确
```

每一步都有正确数据，再进入下一层。

## 安全

- 首次运行先架空底盘、限制电流并准备断电；
- 调云台先降低输出和角度范围；
- 发射机构拆弹并关闭摩擦轮；
- 不要在关闭中断的临界区使用依赖系统 tick 的延时；
- 不要为了消除报错随意删除安全检查或离线处理。
