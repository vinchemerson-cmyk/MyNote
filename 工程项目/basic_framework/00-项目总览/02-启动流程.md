# 启动流程

## 总链路

```text
Reset_Handler
→ SystemInit
→ main
→ HAL_Init + 时钟配置
→ CubeMX 外设初始化
→ RobotInit
→ MX_FREERTOS_Init
→ osKernelStart
```

## main 阶段

`Src/main.c` 先初始化 GPIO、DMA、ADC、CAN、SPI、TIM、UART、IIC、CRC、DAC 等外设，然后调用唯一的整车初始化入口 `RobotInit()`。

## RobotInit

`application/robot.c` 中的顺序：

1. `__disable_irq()`：初始化期间关闭中断。
2. `BSPInit()`：初始化 DWT 时间基准和 SEGGER RTT 日志。
3. 根据板型宏初始化 Application。
4. `OSTaskInit()`：创建项目自定义 FreeRTOS 任务。
5. `__enable_irq()`：初始化完成后重新打开中断。

当前 `ONE_BOARD` 配置实际调用：

```text
RobotCMDInit()
ChassisInit()
OSTaskInit()
```

`GimbalInit()` 和 `ShootInit()` 当前被注释。

## FreeRTOS 启动

`MX_FREERTOS_Init()` 还会创建 CubeMX 默认任务。调度器启动后，默认任务初始化 USB Device，然后调用 `osThreadTerminate(NULL)` 结束自身。

## 注意事项

- 初始化阶段已经关闭中断，不要调用依赖 SysTick/中断的普通延时。
- 如确实需要等待，项目约定使用 `DWT_Delay()`。
- 各模块注册时会分配实例并可能启动 DMA/CAN 中断，初始化顺序必须考虑依赖关系。
