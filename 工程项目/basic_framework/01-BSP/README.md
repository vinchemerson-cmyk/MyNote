# BSP 总览

BSP 层封装 STM32 片上外设。它与 HAL 和 CubeMX 配置强耦合，但向 Module 层提供相对统一的实例接口。

## 模块状态

| 模块 | 主要用途 | 状态 |
|---|---|---|
| CAN | 设备注册、过滤器、收发和回调分发 | 核心模块，已使用 |
| USART | Receive-to-idle DMA、发送、回调分发 | 核心模块，已使用 |
| USB | CDC/VCP 收发 | 已用于视觉通信 |
| SPI | 阻塞/中断/DMA 收发和片选管理 | 已用于 BMI088 |
| IIC | 主机收发与存储器访问 | 有封装，部分传感器使用 |
| GPIO | 普通 IO 与 EXTI 回调 | 已实现 |
| PWM | 占空比、周期和 DMA 输出 | 蜂鸣器、舵机、加热使用 |
| ADC | ADC 封装 | 当前文件基本为空，占位状态 |
| DWT | 高精度时间、延时、执行时间测量 | 核心基础设施 |
| Log | SEGGER RTT 日志 | 核心调试设施 |
| Flash | 片内 Flash 擦写 | 已实现，使用需谨慎 |
| bsp_tools | 把复杂中断回调转移到任务 | 已实现，使用较少 |

## 阅读方法

先读每个头文件中的 `Instance`、`Init_Config` 和公开函数，再读注册函数，最后看 HAL 回调。不要先陷入 HAL 驱动内部。
