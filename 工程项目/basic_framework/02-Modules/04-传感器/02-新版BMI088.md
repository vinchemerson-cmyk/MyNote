# 新版实例化 BMI088

`modules/BMI088` 是另一套 BMI088 驱动，目标是使用统一 BSP 实例风格替代旧版直接操作 HAL 的实现。

## 设计

`BMI088Instance` 拥有：

- Acc 和 Gyro 两个 SPI 实例；
- Acc/Gyro 数据就绪 GPIO 实例；
- 加热 PWM 与温度 PID；
- 原始/标定后的加速度、角速度、温度；
- 工作模式和更新标志。

## 接口

```c
BMI088Instance *BMI088Register(BMI088_Init_Config_s *config);
uint8_t BMI088Acquire(BMI088Instance *instance, BMI088_Data_t *out);
void BMI088CalibrateIMU(BMI088Instance *instance);
```

支持的设计方向包括周期阻塞读取、触发读取和中断/DMA，但源码明确说明异步实现尚未完整，目前初始化阶段强制先用阻塞模式。

## 当前项目中的使用情况

`RobotCMDInit()` 中有一份该模块的测试配置，但整段被注释。实际 INS 使用的是 `modules/imu/BMI088driver`，不要把两套实例混为同一条链。

## 当前问题

- Daemon 实例变量声明后未真正接入；
- Gyro 中断回调中设备 ID 检查被注释，留下未使用变量；
- DMA/IT 回调的注释和实现仍处于开发阶段；
- 校准模式和预标定参数需要按具体板卡确认；
- 构建启用 `-Werror` 时，未使用变量会直接导致编译失败。

建议把它当成重构中的实验模块，完成单元测试后再替换当前 INS 驱动。
