# 编码器模块

`modules/encoder` 当前只有说明文档，没有 `.c/.h` 实现。

目标是支持光电编码器和霍尔磁编码器。项目文档建议先增加 `bsp_tim`，统一封装：

- 定时器 Encoder Mode 计数；
- Input Capture 周期/频率测量；
- 溢出和多圈累计；
- 定时器更新中断；
- 计数方向、零位和分辨率。

建议未来接口包含：

```text
EncoderRegister(config)
EncoderGetRaw()
EncoderGetAngle()
EncoderGetSpeed()
EncoderReset/SetZero()
```

实现前需要明确编码器类型、每圈计数、倍频方式、减速比、零位传感器和最大转速，避免计数溢出或单位混乱。
