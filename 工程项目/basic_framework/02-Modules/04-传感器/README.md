# 传感器模块总览

| 模块 | 接口 | 用途 | 状态 |
|---|---|---|---|
| INS + 旧版 BMI088 | SPI1 + TIM10 | 当前姿态解算主路径 | 已启用 |
| 新版 BMI088 | BSP SPI/GPIO/PWM | 实例化重构版本 | 实验/未启用 |
| IST8310 | IIC + GPIO | 三轴磁力计 | 已实现，当前未启用 |
| TFminiPlus | IIC | 单点激光测距 | 简单实现，有明显待修问题 |
| Encoder | 计划中的 TIM BSP | 光电/磁编码器 | 只有说明，占位 |

调试传感器应按：设备 ID → 原始数据 → 单位/方向 → 标定 → 滤波/融合 → Application 使用，逐层确认。
