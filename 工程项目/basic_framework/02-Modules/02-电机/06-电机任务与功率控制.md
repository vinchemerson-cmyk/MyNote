# 电机任务与功率控制

## MotorControlTask

统一任务约 1 kHz 调用：

```c
DJIMotorControl();
PowerControl();
DMMotorTask();
```

LK、HT 集中控制和步进电机调用当前被注释；HT 可使用独立任务模式。

## 功率控制模块

`power_control.c` 复制了 DJI 电机的注册、反馈和分组发送框架，但在速度 PID 输出后增加功率估算和统一缩放。

默认底盘通过：

```c
PowerControlInit(&motor_config);
```

注册四个 M3508，因此这些实例由 `PowerControl()` 管理，而不是普通 `DJIMotorControl()`。

## 估算流程

1. 每个电机速度环计算原始力矩/电流目标；
2. 使用标定系数 `K1/K2/constant` 估算单电机功率；
3. 累加得到 `initial_total_power`；
4. 若超过 `chassis_max_power`，按比例分配功率；
5. 反解允许的电流目标并限幅；
6. 填充 DJI 分组 CAN 帧。

`SetPowerLimit()` 由 Chassis 每周期使用裁判系统功率限制更新。

## 当前风险

- 参数是针对特定电机/机构的经验模型；
- 负功率处理、判别式和零功率边界需要验证；
- 裁判系统数据未就绪时最大功率可能为 0；
- 缓冲能量 PID 和超级电容尚未完整接入；
- 代码仍有未使用变量，说明实现处于调试阶段。

上车前应在架空和限流条件下验证功率估计、输出限幅和 CAN 电流方向。
