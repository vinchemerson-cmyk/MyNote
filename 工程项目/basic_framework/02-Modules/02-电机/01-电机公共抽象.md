# 电机公共抽象

`motor_def.h` 定义各电机共用的控制概念。

## 闭环类型

`Closeloop_Type_e` 使用位标志表示：

- `OPEN_LOOP`；
- `CURRENT_LOOP`；
- `SPEED_LOOP`；
- `ANGLE_LOOP`。

`close_loop_type` 可组合多个环；`outer_loop_type` 指定调用者提供的是最外层哪一种目标。

## 反馈源

- `MOTOR_FEED`：使用电机自身编码器/速度反馈；
- `OTHER_FEED`：使用 IMU、外部编码器等指针提供的数据。

云台是典型例子：Yaw/Pitch 角度和角速度可来自 INS，而不是电机编码器。

## 方向

- `motor_reverse_flag`：反转控制输出/参考方向；
- `feedback_reverse_flag`：反转反馈方向。

调试新电机的第一件事是分别确认“正目标是否产生正运动”和“正运动是否产生正反馈”，不要用错误 PID 参数掩盖方向问题。

## Motor_Controller_s

保存三环 PID、当前参考值，以及外部角度/速度反馈和前馈指针。

## 初始化配置

`Motor_Init_Config_s` 把以下配置集中起来：

- CAN 配置；
- 三环 PID 参数；
- 闭环、方向、反馈源和前馈设置；
- 电机型号。

不同电机模块复用这套配置，但对协议和可用控制模式的解释不完全相同。
