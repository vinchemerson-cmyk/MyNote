# 舵机与步进电机

## Servo Motor

舵机模块基于 PWM BSP，把目标角度映射到 PWM 高电平时间/占空比。

```c
ServoInstance *ServoInit(Servo_Init_Config_s *config);
void ServoSetAngle(ServoInstance *servo, float angle);
```

实例配置包含 PWM 参数、角度范围和工作模式。使用时必须按具体舵机校准：

- 控制周期通常约 20 ms，但以说明书为准；
- 最小/最大脉宽决定角度端点；
- 机械结构可能小于舵机理论范围；
- 上电目标突变可能造成撞限位。

文件中存在尚未完整使用的 `DecodeServo()`，说明反馈舵机支持仍不完善。

## Step Motor

`modules/motor/step_motor/step_motor.c` 和 `.h` 当前为空，是占位模块。统一 Motor Task 中的 `StepMotorControl()` 也被注释。

后续实现至少要区分：

- STEP/DIR 驱动器还是四相线圈驱动；
- 定时器输出频率与加减速曲线；
- 位置累计和回零传感器；
- 中断/DMA 脉冲生成；
- 失步检测和急停行为。
