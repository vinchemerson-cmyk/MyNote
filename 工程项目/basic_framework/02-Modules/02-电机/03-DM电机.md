# DM 电机

DM 模块封装达妙电机 CAN 协议，支持普通控制和 MIT 控制两套初始化方式。

## 两种模式

### 普通模式

`DMMotorInit()` 使用 `DMMotor_Init_Config_s`，可按公共电机抽象运行位置/速度等闭环。

### MIT 模式

`MITMotorInit()` 使用 MIT 参数，控制帧包含位置、速度、KP、KD、力矩等量。浮点数会按协议范围量化为固定 bit 数。

## 接口

```c
DMMotorSetRef(...);
DMMotorOuterLoop(...);
DMMotorChangeFeed(...);
DMMotorSetMITAngle(...);
DMMotorSetMITSpeed(...);
DMMotorSetMITTorque(...);
DMMotorEnable(...);
DMMotorStop(...);
DMMotorCaliEncoder(...);
DMMotorTask();
```

## 特殊命令

使能、停止和编码器校零通过特殊控制帧发送，不是普通 PID 目标。使用前需要确认电机固件模式和 CAN ID 设置与代码一致。

## 反馈与恢复

回调解析位置、速度、力矩、温度和错误状态。代码包含通信自动恢复逻辑；调试时应观察错误枚举和在线状态，而不是只判断电机是否转动。

## 注意

- MIT 协议量化存在范围和精度限制；
- 位置、速度、力矩的单位必须按电机协议确认；
- KP/KD 过大可能造成刚性冲击；
- `DMMotorTask()` 已在统一 Motor Task 中调用。
