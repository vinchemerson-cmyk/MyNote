# 遥控器模块

## 支持类型

- `RemoteControlInit()`：DJI DT7/DR16 DBUS 数据；
- `FS_RemoteControlInit()`：另一套 FS/SBUS 风格遥控数据。

当前机器人使用 UART3 上的 DJI 遥控器。

## 接收流程

```text
UART Receive-to-idle DMA
→ RemoteControlRxCallback
→ DaemonReload
→ sbus_to_rc
→ 更新 rc_ctrl[TEMP]
→ RobotCMDTask 读取
```

## RC_ctrl_t

包含：

- 左右摇杆和拨轮；
- 左右三段开关；
- 鼠标 X/Y 和左右键；
- 16 位键盘位域；
- 按键状态与计数。

`TEMP` 保存当前数据，`LAST` 保存上次数据，便于识别按下沿、释放沿和按键次数。

## 离线处理

遥控器每次收到合法长度数据就喂 Daemon。约 100 ms 未更新时：

- 清空遥控器数据；
- 重新启动 UART DMA 接收；
- 输出离线日志。

`RemoteControlIsOnline()` 可供安全逻辑使用，但当前 RobotCMD 的急停注释表明离线联锁仍需进一步完善。

## 调试

先观察原始 18 字节帧长度，再检查摇杆中心是否接近零、范围是否合理、开关值是否为定义的 1/2/3。不要在数据未稳定前直接使能电机。
