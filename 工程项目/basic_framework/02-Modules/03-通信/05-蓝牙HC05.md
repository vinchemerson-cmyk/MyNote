# 蓝牙 HC05

HC05 模块通过 USART BSP 实现简单定长帧通信。

## 帧格式

```text
0xAA | payload | 0x55
```

有效数据长度由 `HC05_DATASIZE` 决定。

## 接口

```c
HC05 *HC05Init(UART_HandleTypeDef *uart);
void HC05_SendData(uint8_t *data, uint8_t count);
```

初始化注册 UART 回调；收到数据后只检查帧头和帧尾，再复制 payload。发送使用 UART 中断模式。

## 限制

- 没有 CRC、序号和超时状态；
- 没有 Daemon 在线检测；
- `data_num` 需要调用者保证不超过 `HC05_DATASIZE`；
- 定长接收对丢字节和错位恢复能力弱；
- 适合简单调试，不适合高可靠核心控制。
