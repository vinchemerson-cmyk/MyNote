# 超级电容

超级电容模块通过 CAN 接收电容状态，并可发送 8 字节控制数据。

## 当前配置

Chassis 使用 CAN2：

- 电容反馈 ID：`0x301`；
- 主控发送 ID：`0x302`。

## 数据

反馈前 6 字节解析为：

- `cap_vol`：电容电压；
- `power_in`：裁判系统/电管输入功率；
- `power_chassis`：底盘输入功率。

原始无符号 16 位值除以 1000 转换为浮点。

## 接口

```c
SuperCapInstance *SuperCapInit(SuperCap_Init_Config_s *config);
void SuperCapSend(SuperCapInstance *instance, uint8_t *data);
```

源文件还实现了 `SuperCapGet()`，但头文件没有声明，属于接口不完整。

## 当前限制

- 使用全局 `super_cap_instance` 解码，实际只支持一个实例；
- 没有 Daemon 在线检测；
- `SuperCapSend()` 固定复制 8 字节，调用者必须保证缓冲区足够；
- Chassis 虽然初始化了电容，但当前功率限制逻辑没有真正使用电容反馈；
- 协议缩放比例必须与具体超级电容固件一致。
